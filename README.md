
# Python 기초 퀴즈 게임

## 1. 프로젝트 소개
Python 기초 문법을 학습하고 복습할 수 있는 콘솔 기반 퀴즈 게임입니다.

## 2. 주제 선정 이유
Python을 공부하면서 배운 기본 개념을 문제로 풀어보고,
직접 퀴즈를 추가하며 학습 내용을 복습하기 위해 선정했습니다.

## 3. 주요 기능
- 퀴즈 풀기
- 새로운 퀴즈 추가하기
- 전체 퀴즈 목록 확인하기
- 최고 점수 확인하기
- 프로그램 종료하기
- 퀴즈와 최고 점수를 JSON 파일에 저장하기

## 4. 개발 환경
- OS: Windows + WSL Ubuntu
- Python: 3.14.4
- Git: 2.53.0
- 편집기: Visual Studio Code

## 5. 실행 방법
추후 프로그램 구현 후 작성할 예정입니다.

## 6. 프로젝트 구조
추후 프로그램 구현에 따라 업데이트할 예정입니다.

## 7. 데이터 저장 구조
`state.json` 파일에 퀴즈 데이터와 최고 점수를 저장할 예정입니다.

## 8. Git 학습 내용
브랜치 생성, 커밋, 병합, push, pull, clone 등을 실습할 예정입니다.
